# ЛР-2. Експертна система «Вибір типу комп'ютерної мережі» (варіант 12)

Пінчак В.Б., КН-2327Б

Система моделює консультацію мережевого інженера з замовником: ставить 12 зрозумілих питань
(з варіантом «не знаю»), виводить попередню рекомендацію щодо масштабу, архітектури,
середовища передачі й топології мережі з рівнем впевненості, пояснює хід міркувань і
показує, що треба уточнити. Остаточне рішення - за інженером.

## Запуск
```
pip install flask
python app.py        # http://127.0.0.1:5001
```

## Структура
- `es/knowledge_base.py` - база знань: питання, висновки, 63 продукційні правила з CF
- `es/engine.py` - машина виведення (пряме виведення, комбінування CF за MYCIN, пояснення)
- `app.py` - сервер Flask, `static/index.html` - інтерфейс
- `scenarios.py` - типові замовники для перевірки
